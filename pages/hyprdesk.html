HyprDesk – Panel de ajustes para Hyprland

Instalación

Disponible · v1.0.4 Rust iced 0.14 Wayland MIT + Commons Clause

HyprDesk es una herramienta de escritorio desarrollada en Rust con iced, diseñada específicamente para el compositor Hyprland en Wayland. Ofrece un panel centralizado donde puedes ajustar los principales parámetros de tu entorno sin necesidad de editar ningún archivo de configuración manualmente. Desde el brillo de pantalla hasta la gestión de monitores, todo a un clic de distancia.

curl -fsSL https://raw.githubusercontent.com/Besori-Company/HyprDesk/main/scripts/install.sh | bash

Requisitos

El instalador se encarga de descargar todo lo necesario automáticamente.

  • brightnessctl Control de brillo por hardware
  • hyprsunset / wlsunset / gammastep / redshift Modo noche: Usa el que tengas instalado
  • hyprctl Monitores y opacidad: Incluido con Hyprland
  • polkit Escalado de privilegios para cambios de perfil
  • glib2 Comunicación con AccountsService para avatar y nombre de usuario
  • accountsservice Daemon del sistema para la gestión de cuentas de usuario

Funciones

Brillo

Ajusta el brillo de tu pantalla de manera más fácil y sencilla.

Detalles técnicos
Compatible con brightnessctl (ajuste por hardware) y ajuste gamma por software. Detecta automáticamente el método disponible en tu sistema.

Modo noche

Reduce la luz azul para cuidar tu vista en entornos con poca luz. Elige la calidez que más te convenga para cada momento del día.

Detalles técnicos
Temperatura de color ajustable entre 1000 y 6500 K. Compatible con hyprsunset, wlsunset, gammastep y redshift; usa el que tengas instalado.

Monitores

Organiza tus pantallas arrastrándolas a la posición que necesites. Configura resolución, frecuencia, orientación, escala y pantalla principal desde un único lugar.

Detalles técnicos
Los cambios se aplican con hyprctl keyword y se guardan en la configuración de Hyprland para que persistan entre reinicios.

Opacidad

Controla la transparencia de tus ventanas de forma global o por aplicación.

Detalles técnicos
Control independiente para ventanas activas e inactivas. Identificación de la aplicación por nombre de clase Wayland; seleccionable desde las ventanas abiertas o introduciendo el nombre manualmente.

Perfil

Actualiza tu foto de perfil, cambia tu nombre de usuario y elige el idioma de la interfaz.

Detalles técnicos
Permite cambiar también el locale del sistema además del idioma de la aplicación. Los cambios de nombre de usuario se aplican directamente en la configuración del sistema.
